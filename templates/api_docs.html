API Overview

The NLP Text Analyzer API provides programmatic access to our natural language processing capabilities. Use our API to analyze text, extract insights, and integrate powerful NLP features into your own applications.

Base URL
https://api.nlpanalyzer.com/v1
Authentication

All API requests require authentication using your API key in the headers:

X-API-Key: your_api_key_here

API Endpoints

POST /analyze

Analyze text with specified NLP operations

Request Body
{
  "text": "Your text to analyze goes here.",
  "operations": ["sentiment", "entities", "summary", "keywords", "word_frequencies"]
}
Parameters
Parameter Type Required Description
text String Yes The text content to analyze (maximum 50,000 characters)
operations Array No Array of operations to perform. Defaults to all operations if not specified.
Example Request
curl -X POST https://api.nlpanalyzer.com/v1/analyze \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key_here" \
  -d '{
    "text": "Apple Inc. is an American multinational technology company headquartered in Cupertino, California. Apple is the world\'s largest technology company by revenue, with US$394.3 billion in 2022 revenue. As of March 2023, Apple is the world\'s biggest company by market capitalization.",
    "operations": ["sentiment", "entities", "summary"]
  }'
Example Response
{
  "sentiment": {
    "compound": 0.34,
    "positive": 0.18,
    "negative": 0.0,
    "neutral": 0.82,
    "sentiment": "positive"
  },
  "entities": {
    "ORGANIZATION": ["Apple Inc.", "Apple"],
    "GPE": ["California", "Cupertino"],
    "DATE": ["2022", "March 2023"]
  },
  "summary": "Apple Inc. is an American multinational technology company headquartered in Cupertino, California. Apple is the world's largest technology company by revenue, with US$394.3 billion in 2022 revenue."
}
Rate Limits

Premium tier subscribers are limited to 5,000 API requests per day. Exceeding this limit will result in 429 (Too Many Requests) responses.

Response Headers

Each response includes headers that provide information about your current rate limit status:

Header Description
X-RateLimit-Limit The maximum number of requests allowed per day
X-RateLimit-Remaining The number of requests remaining in the current period
X-RateLimit-Reset The time when the current rate limit window resets (Unix timestamp)
